  网盘管理 V1.0  ·  绿色免安装版
  百度网盘 · 夸克网盘 · 光鸭云盘，一个界面全搞定
========================================================================

【怎么用】三步
------------------------------------------------------------
  1) 解压：把压缩包整个解压到一个普通文件夹
     （别放 C:\ 根目录、别放 "Program Files"、别放需要管理员权限的地方；
       也请**不要**直接在压缩包里双击运行）

  2) 启动：
        Windows —— 双击  启动.exe
        Linux   —— 双击  启动.sh（或在终端里 ./启动.sh）

  3) 登录：打开某个网盘页 → 点「登录 / 管理」→ 用手机 App 扫码
     登录一次就一直记得（凭证存在你自己的文件夹里）

【放到桌面 / 开始菜单】
------------------------------------------------------------
  Windows：双击  创建桌面图标.bat
  Linux  ：执行  ./创建桌面图标.sh
  （只写你自己的用户目录，不碰系统）

【界面卡顿？用诊断模式抓证据】
------------------------------------------------------------
  命令行里这样启动（把卡顿现场记进日志）：
      运行环境\venv\Scripts\python.exe 启动.py --性能诊断

  它会把"界面卡住时主线程正在做哪一行"写进  数据\卡顿诊断.log，
  还会记录：系统版本 / Python / 平台插件 / 屏幕分辨率与缩放倍数。

  复现一次卡顿后，把 数据\卡顿诊断.log 发给作者即可定位。
  （诊断只写日志、不改行为；不加这个参数就完全没有影响。）

【启动没反应 / 想看报错】
------------------------------------------------------------
  1) 先看  数据/一键启动.log
     每次启动都会记一行（时间 / 解释器 / 退出码 / 是否"已经在运行"）。
     如果写着 already running：程序**已经在运行**了 —— 到任务栏或别的桌面找找窗口；
     确实找不到，先把它关掉再启动（想强制再开一个：命令行 V83_FORCE=1 ./启动.sh）。

  2) Windows：双击  启动（看报错）.bat   —— 保留一个黑窗口，报错直接看得到
     Linux  ：在终端里执行  ./启动.sh

  3) 程序自己的日志：数据/界面日志.txt（界面里「日志」页也是同一份）

  常见原因：
   * 已经在运行（窗口被最小化 / 在别的桌面）→ 见上面第 1 条
   * 运行环境 目录被删或改名 → 报"没找到包内自带的解释器"，重新解压完整包即可
   * 放在只读目录 / 空间不足 → 程序要能往自己的目录写 数据/ 目录

【为什么这么"绿"】
------------------------------------------------------------
  * 解释器（Python 3.14）、界面库（PySide6/Qt6）、AI 模型全都在这个文件夹里；
  * 不写注册表、不装系统包、不动 ~/.config 与 ~/.cache；
  * 缓存、日志、登录凭证全部落在本文件夹内；
  * 整个文件夹可以随便复制/改名/搬到 U 盘或别的电脑；
  * 不想要了 —— 直接删掉整个文件夹，不留任何残留。

【两个版本的区别】
------------------------------------------------------------
  完整版：含 AI 语音识别模型（460 MB），字幕功能离线可用；
  精简版：不含模型，包小 460 MB；第一次用「AI 生成字幕」时会自动联网下载
          （已内置国内镜像 hf-mirror.com，不需要科学上网）。

【更新】
------------------------------------------------------------
  打开「⚙ 设置 → 🔄 软件更新 → 检查更新」，一键更新并自动重启。
  只覆盖程序本体，**不会动**你的 配置.json、数据/ 与网盘登录凭证。

【常见问题】
------------------------------------------------------------
  Q: 需要先装 Python 吗？         A: 不用，全都在包里。
  Q: 会不会上传我的文件？         A: 不会。传输是你本机直接跟网盘服务器通信，
                                     本地 AI 模式一个字节都不出本机。
  Q: 杀毒软件报警？               A: 绿色版打包的 Python 程序偶尔会被误报，
                                     加信任即可；源码全部公开在 GitHub，
                                     不放心的可以自己从源码跑。
  Q: 支持哪些系统？               A: Windows 10/11 64 位、Linux x86_64。
