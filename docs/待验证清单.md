## 2. 三家真实后端的桥路验证（联网只读，不碰真凭证）

三家子代理各写了验证脚本（都做了"复制适配器项目到临时目录、不含 `数据/`、只走失败路径"）：

```bash
# 夸克
$PY /run/user/1001/验证_夸克统一登录.py                # 可加参数指定可写临时根
# 光鸭
bash /var/tmp/光鸭登录自检_运行.sh
# 百度（自包含版，见下方）
```

每个脚本都会：打印 `登录方式表()`、`扫码开始()`（图片只打前 40 字符）、
用**无效凭证**走失败路径（绝不动真实登录数据），并在结尾核对真实
`数据/会话.json`、`数据/令牌.json`、`数据/凭证.json` 的 `size+mtime` 未被改动。

百度版（自包含，含"真凭证 md5 前后一致"核验）：

```bash
SRC="<项目根>/适配器/百度网盘适配器"
TMP=$(mktemp -d /tmp/百度适配器副本.XXXXXX)
tar -C "$SRC" --exclude='__pycache__' --exclude='数据' -cf - 核心 启动.py 项目配置.toml | tar -C "$TMP" -xf -
md5sum "$SRC/数据/会话.json"        # 跑前记下，跑后必须一致
cd <项目根>
$PY - "$TMP" <<'PY'
import sys
from v8_3.核心.适配器 import 适配器规格
from v8_3.核心.子进程客户端 import 子进程适配器
from v8_3.核心.模型 import 网盘类型
适配器 = 子进程适配器(适配器规格(类型=网盘类型.百度, 项目根=sys.argv[1]))
适配器.启动()
print("== 登录方式表 =="); print(适配器.登录方式表())
信息 = 适配器.扫码开始(); print("== 扫码开始 ==")
for k, v in 信息.items():
    print(f"  {k} = " + (f"{v[:40]}…（base64 长度 {len(v)}）" if k == "图片base64" else repr(v)))
print("== 无效 Cookie 失败路径 ==")
print(适配器.Cookie登录("BDUSS=invalid-test-only; STOKEN=invalid"))
print("== 账号状态 =="); print(适配器.账号状态())
适配器.关闭()
PY
md5sum "$SRC/数据/会话.json"        # 必须与跑前一致
rm -rf "$TMP"
```

预期（**子代理未观测，仅为预期**）：能力表 qrcode/cookie 支持、sms/email/token/password
不支持；扫码开始返回真二维码 PNG 的 base64；`Cookie登录` 返回
`{"状态":"失败","消息":"Cookie 未被服务端接受：…errno:-6","提示":…}`，
且临时副本的 `数据/会话.json` 被回滚删除。

**子代理自报的残留风险（未验证）**：百度 `login_qr_wait` 取消后要等当前
unicast 长轮询返回（最长约 60 秒）才真正退出；夸克/光鸭同理。界面侧已按
"超时＝可重试"处理（`登录对话框._像超时`），关闭对话框会调用 `扫码取消`。
