# 传输界面说明（V8 形态：分类标签 + 8 列 + 操作）

2026-09-16 起，传输页的任务表格按 **网盘管理_V8** 的形态重做：
不同状态的任务分门别类放进对应分类，方便快速管理和维护。

## 一、分类标签（点一下只看这一类）

| 标签 | 收录的引擎状态 | 说明 |
|---|---|---|
| 📋 全部 | 所有 | 默认视图；行序：进行中 → 失败 → 暂停 → 等待 → 跳过 → 已完成 |
| 🔄 进行中 | 下载 / 上传 / 枚举 | 正在跑的任务（状态列还会细分「🔄 下载中 / 🔄 上传中 / 🔍 扫描中」） |
| ✅ 已完成 | 完成 | 含"兜底成功"的任务（状态列标「（兜底）」） |
| ⏳ 等待 | 等待 | 排队中，等并发额度 |
| ⏸ 暂停 | 暂停 | 用户暂停的任务；**已保留断点，继续时可续传** |
| ⏭️ 跳过 | 跳过 | 目标已存在 / 同名不同大小等（原因写在状态列） |
| ❌ 失败 | 失败 / 已取消 | 状态列直接拼上失败原因摘要 |
| 🚧 未完成 | 进行中 + 等待 + 暂停 | 与 V8 的「未完成」定义一致（**失败不算未完成**） |

标签上带实时计数（如 `❌ 失败 (2)`），当前分类用颜色高亮。

## 二、表格列

| 列 | 内容 |
|---|---|
| 文件名 | 源路径；悬停显示目标路径 |
| 类型 | 📤 上传 / 📥 下载 / 🔀 跨网盘 |
| 大小 | `已传输 / 总大小` |
| 进度 | 进度条：`37%`、`✅ 100%`、`❌ 33%`、`⏸ 62%`、`⏳ 等待中` |
| 速度 | 实时速度（`3.2 MiB/s`）；结束时显示状态图标 |
| 耗时 | 运行中 = 已耗时；结束 = 总耗时（结束 - 开始） |
| 状态 | 状态 + **跳过/失败原因摘要**（悬停看全文） |
| 操作 | 5 个按钮：⏸ 暂停 · ▶ 继续 · 🔄 重试 · ℹ️ 详情 · 🗑 取消/移除 |
| 完成/失败时间 | **只在「已完成」「失败」分类里显示**：已完成→表头「完成时间」；失败→「失败时间」；其它分类自动隐藏，不挤占视图 |

## 三、操作与右键菜单

* **操作列**：按任务状态自动启用/禁用（例：失败任务上"暂停"置灰，"详情/重试/继续"可用）。
* **双击某行** → 打开**任务详情对话框**：任务 ID、状态、类型、进度、源/目标网盘与路径、
  目标实际落盘名、开始/结束时间、耗时、重试次数、阶段、本地中转、批次，
  以及**完整失败原因**；底部四个复制按钮（全部 / 失败原因 / 源路径 / 目标路径）。
* **右键某行** → 查看详情 · 暂停 · 继续 · 重新传输 · 复制源路径 · 复制目标路径 ·
  复制失败原因 · 打开本地中转目录 · 取消/移出列表。
* **分类栏右侧**：`⏸ 全部暂停` · `▶ 全部继续` · `📤 导出列表`（把当前分类导出 CSV：
  文件名/类型/大小/已传/状态/进度/开始时间/结束时间/耗时/重试次数/源与目标/实际落盘名/原因/阶段）。

## 四、暂停/继续的语义（已实测）

* **排队中的任务**：暂停后停在队列里不开跑（不占并发、不占磁盘）；
  `▶ 全部继续` 后立刻放行。
* **正在跑的任务**：在**下一个进度回调的安全点**停下 ——
  分片与前缀都会保留，任务记为「⏸ 暂停（已保留断点，继续时可续传）」；
  继续时若本地已有完整数据，**直接复用不再重下**（实测日志：
  `[引擎] 断点续传：… 复用已下载 12.0 MiB`）。
* 实现要点（踩过的坑）：暂停必须由 **桥进程内部**在进度回调里抛错才有效；
  在引擎侧回调里抛异常会被客户端的读线程吞掉，任务照跑。
  暂停/继续都要**同步清掉桥里的停止标记**，否则重跑会立刻又被停。
